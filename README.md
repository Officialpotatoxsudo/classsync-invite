# ClassSync invite landing page

Public, dependency-free landing page for ClassSync invite links. It reads the
`code` query parameter, shows the invite code, and redirects Android visitors
into the app with `classsync://join/<code>`.

Live at:

```
https://officialpotatoxsudo.github.io/classsync-invite/?code=<code>
```

The app source lives in a separate private repository.
